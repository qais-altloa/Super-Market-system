# Super-Market-system

A C++ based supermarket management system designed to simulate real-world retail operations using Object-Oriented Programming and Data Structures.

## Features
- Inventory and stock management
- Customer shopping cart system
- Order processing
- Promotions and discount handling
- Sales analytics and reporting
- Admin/User management
- Tree-based product organization and searching

## Technologies & Concepts
- C++
- Object-Oriented Programming (OOP)
- Data Structures and Algorithms
- Trees
- Modular system design

## Project Structure
- `Inventory_Management.h` → inventory and stock operations
- `Customer_Cart.h` → customer cart management
- `Order.h` → order handling and checkout
- `Promotion.h` → discounts and promotional logic
- `Analytics.h` → sales analysis and reporting
- `User_Admin.h` → admin and user functionality
- `Tree.h` → tree data structure implementation
- `SuperMarket.cpp` → main application

## How to Run
1. Open `SuperMarket.sln` in Visual Studio
2. Build the solution
3. Run the project

## Objective
This project demonstrates practical implementation of data structures, modular programming, and OOP concepts through a real-world supermarket simulation system.
